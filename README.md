# HackClubRepository
Currency Converter
A fully web based currency converter built with HTML, CSS, and JavaScript featuring statistics display, tracking, conversion history, local storage persistence, theme customization, AND export functionality.

Key features
- Currency Conversion
- Export history to save locally
- Conversion history saving
- Local storage persistence
- Conversion statistics
- Dark, Ultra, and Lide themes

Codes: HTML, CSS, JS.
