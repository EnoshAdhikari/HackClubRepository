# HackClubRepository
Currency Converter
A fully web based currency converter built with HTML, CSS, and JavaScript featuring statistics display, tracking, conversion history, local storage persistence, theme customization, AND export functionality.

Key features
- Currency Conversion
- Export history to save locally
- Conversion history saving
- Local storage persistence
- Conversion statistics
- Dark, Ultra, and Lide themes

Codes: HTML, CSS, JS.

How to run: You can download or clone this repository, or you can go visit: https://codepad.app/pad/u32124a1 to try it!
If you choose to download or close this repo:
Step 1: Download it
Step 2: Open the project folder
Step 3: Open index.html in a web browser
Step 4: Enter an amount, choose currencies, and click Convert
Note: Please feel free to mess around and check out the websites interesting features!
